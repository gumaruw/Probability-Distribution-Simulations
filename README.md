# Probability Distribution Simulations

## Description
Simulates different probability distributions (Normal, Binomial, Poisson, Exponential) and visualizes them using Matplotlib. Also computes summary statistics (mean, median, variance) for each distribution.

## Usage
1. ```bash
   pip install -r requirements.txt
2. ```bash
   python ProbabilityDistribution.py

## Techniques
- Random number generation with NumPy
- Probability distributions (Normal, Binomial, Poisson, Exponential)
- Visualization with Matplotlib
- Summary statistics (mean, median, variance)

## Dependencies
- NumPy
- Matplotlib
